# Wardrobe Ledger

`index.html` is the source of a Claude artifact. The live copy is https://claude.ai/artifact/7xQC1kFbFuVqE2jUba7kKY, published with the capabilities listed in README.md.

## Keep the repo in sync with the live page

- Whenever you republish the artifact, commit the exact `index.html` you published to this repo in the same session and push it. Write a commit message that says what changed on the page.
- If the artifact was changed somewhere else, read it with the Artifact tool (action "read", path "index.html") and commit that version before you make your own edits.
- If you change the weekly routine's prompt, update `routine-prompt.md` to match. Keep the `YOUR_ARTIFACT_URL` placeholder and the first-person wording, so it stays reusable.
- Never commit closet data, photos, or anything read from Gmail. Only the page source and docs belong here.
